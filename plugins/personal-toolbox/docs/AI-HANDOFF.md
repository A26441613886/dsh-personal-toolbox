# DeepSeek Harness：给所有 AI 的维护说明

本项目是用户的 DeepSeek Harness 本地定制版。无论是 ChatGPT、Grok、Claude、Cursor 还是其他 AI，在修改本项目之前都必须先阅读：

- `AGENTS.md`
- `README.md`
- `plugins/personal-toolbox/config/patches.json`

## 统一插件源码目录

唯一长期源码根目录是 `plugins/personal-toolbox/`，先读其 `README.md` 和 `docs/DIRECTORY.md`。源码按 `src/`、`compat/`、`config/`、`assets/`、`locale/`、`tools/`、`tests/`、`docs/` 分类；常用提示词已从生成包收纳到 `src/prompts/`。`packages/` 只是运行输出，现有包名、4 个组件 ID 和启用状态保持。

旧 `patches/*.mjs` 只是兼容入口，不维护第二份源码。改源码后只检查和构建，不调用启动器、不自动重启、不反复自动测试页面。`tools/export-source.mjs` 导出数据隔离的源码包及 SHA-256 清单；用户数据仍在原 DSH_HOME、浏览器存储和 output/intelligence-tests。

## 最重要的规则

消费总览是「星潮工具箱」组件列表中与「余额与消费」并列、可分别开关的独立组件；点击组件在插件详情打开统计页，不在应用主侧栏添加入口。维护 `plugins/personal-toolbox/src/spending/client.js`、`plugins/personal-toolbox/src/spending/host.js`、`plugins/personal-toolbox/src/shared/services.js` 和 builder；本机 `personal-spending.sqlite` 及原 `balance-history.json` 都需保留。余额差额与模型估算独立、币种分别统计、未知价格不记为免费；模型单价可编辑且重算历史估算。主指标显示今天总花费，时间范围为当天、7 天、30 天和全部；逐日趋势一天一根柱，柱高是当天合计。插件详情介绍区明确 4 个宿主组件 + 1 组配套兼容层；组件列表下方显示兼容层总开关及模型切换与多密钥菜单、模型设置、思考滑条、会话菜单、技能菜单 5 个子项，沿用本机状态，刷新生效，不删除配置。JSX 调用必须传 props（包括空对象）；client inject 包含 plugin-manager。文件夹按钮打开完整 plugins/personal-toolbox 插件源码目录，版本标签和按钮并排，成功/失败给出路径反馈。测试为 `node plugins/personal-toolbox/tests/verify-personal-spending.mjs`。

不要只修改 `node_modules` 里的文件。

`node_modules` 是安装依赖生成的目录，更新或重新安装后会被官方文件覆盖。所有界面和功能定制的长期源文件都在 `plugins/personal-toolbox/`：

- `plugins/personal-toolbox/compat/models/client.js`：模型设置、密钥、余额查询、获取模型、编辑弹窗分类页（自定义/密钥/模型/余额）、紧凑模型条目
- `plugins/personal-toolbox/compat/models/host.js`：模型设置 onboarding 兼容适配
- `plugins/personal-toolbox/src/shared/services.js`：插件所属的余额查询后端、按天消费记录、独立智力检测请求（不创建会话）
- `plugins/personal-toolbox/compat/connection/client.js`：连接状态显示、终端断线顶部横幅、输入框加载卡住兜底
- `plugins/personal-toolbox/compat/model-selection/client.js`：会话模型选择菜单按供应商、命名密钥、模型分组；模型选择器显示供应商名称、推理强度中文滑条（含「无」，已移除最低档位）；离线回归 `node plugins/personal-toolbox/tests/verify-model-selection-keys.mjs`
- `plugins/personal-toolbox/compat/routing/pi-ai.js`：多密钥、按模型路由、模型发现、默认推理强度、选「无」不发思考参数、重试
- `plugins/personal-toolbox/compat/routing/llm.js`：选「无」时即使模型未声明思考档位也不拦截
- `plugins/personal-toolbox/compat/sessions/client.js`：工作区/会话重命名和归档按钮
- `plugins/personal-toolbox/compat/skills/client.js`：输入框 `/` 菜单把技能分组放在最前面，刷新过期的空技能目录，并用简短中文显示用途
- `plugins/personal-toolbox/src/prompts/`：输入框常用提示词（保存在本机浏览器）
- `plugins/personal-toolbox/src/intelligence/client.js`：插件所属的独立智力检测工作台、从 Harness 模型目录选择检测目标并静默后台测试、多个目标并行运行、鹈鹕 SVG 动画预览 / 糖果推理双测试；时间轴四色状态和分时段详情、本地预览与历史记录、内置糖果提示词（兼容旧本机配置）

- 通用设置不显示智力检测提示词编辑区，避免把检测专用配置混入通用设置。

- 主模型选择器和智力检测弹窗统一不显示最低思考档位；已有最低配置迁移到可用的低档或模型默认，其他请求参数保持不变。

- 智力检测可按目标选择模型支持的思考强度（默认沿用模型设置）和 3–30 分钟总时限；实时显示等待、思考/正文数量，区分取消、供应商超时与总时限，保留未完成正文供排查。

- 鹈鹕预览保留完整 HTML / SVG、原有 CSS 和 JavaScript，在 sandbox allow-scripts iframe 内隔离展示；不注入样式或动画，已有记录优先从原始答复恢复

- 智力检测页右上角“打开生成文件夹”只以可见 Windows 资源管理器打开 output/intelligence-tests；不读取或重新导出历史、不恢复已删除文件，空目录也可打开；新检测完成后的自动保存独立保留，禁止对资源管理器使用隐藏窗口参数。

- 智力检测卡片标题仅突出显示供应商 · 模型，去掉重复模型名、装饰图标和测试方式小字；长名称省略并可悬停查看完整名称。

- 智力检测卡片右上角编辑弹窗统一修改同供应商模型、思考强度和等待时限；卡片不常驻设置栏，测试中禁止编辑，保存才生效，切换模型保留并分别展示各模型历史。

- 智力检测卡片以全部通过率和成功/部分成功/失败次数展示；时间轴按最近 24 小时（每格 30 分钟）、7 天或 30 天自动推进，未检测灰色、全部成功绿色、部分题目成功橙色、全部失败红色；同格按最后一次检测着色并可查看所有记录，未检测不计入通过率，使用 questions 数组保存同轮两题结果。

- 鹈鹕检测提示词使用用户原文，不追加交付格式、不禁止工具、终端、浏览器、JavaScript 或外部资源

- 智力检测结果工具栏提供全部检测按钮：并行启动所有空闲且配置完整的目标，沿用每个目标的模型、思考强度和等待时限，跳过运行中目标，全部运行时禁用并显示检测数量；单个失败不影响其他检测。

- 智力检测的添加检测模型入口使用独立居中模态弹窗，不向下展开或挤动结果卡片；弹窗保留模型列表、组合检测说明、思考强度、等待时限和刷新，支持关闭、取消及 Esc，保存后关闭并添加目标。

- 智力检测两题按用户原始提示词发送，不追加格式、答案、工具或脚本限制；完整保留模型正文、思考内容和工具调用，不因工具调用而报错；工具调用仅记录、不自动执行本地工具；HTML/SVG 原始文档在隔离 iframe 内预览并原样保存，不替换背景、不删脚本、不添加动画；用户选择的思考强度和等待时限继续生效。

- 鹈鹕预览以 240px 为高度上限、宽度不超过卡片；完整页面等比例缩小后，窗口宽高贴合实际画面并居中，取消外围边框和上下黑色留边，不裁切内容、不显示内部滚动条；尺寸测量仅用于预览副本，不修改提示词、原始答复、保存文件或模型动画。

- 糖果答案仅在本地解析副本中兼容自然语言结论、Markdown、HTML、中文数字、全角数字和 LaTeX 公式；不推算未给出的答案，不把数量表或明确否定、假设、二选一结论当答案；已完成旧记录从保存的原始正文重新识别并更新展示和时间轴，不改提示词或原始答复，不重新调用模型。

- 智力检测卡片不显示“查看上游原始答复”折叠栏及对应引导文案；保留动画预览、糖果最终答案、历史原始数据和时间轴详情。

- 智力检测总览页面隐藏主滚动条，保留鼠标滚轮、触控板和键盘滚动；样式仅作用于检测页主容器。

- 智力检测页顶部导航移除“鹈鹕 SVG · 糖果推理”说明文字，仅保留智力检测标签和打开生成文件夹入口。

- 智力检测状态文案统一为绿色“正常”、橙色“半降智”、红色“降智”，用于图例、卡片状态、次数统计和时间轴详情；未检测仍为灰色，判定规则和请求错误原因保持原样。

- 智力检测支持详细模式与预览模式切换并在本机记住选择；预览模式以响应式网格仅展示供应商、模型、开始/取消测试按钮、鹈鹕预览和糖果答案，隐藏卡片统计、时间轴、编辑和删除；复用原有后台组合检测，切换显示不中断测试。

- 详细模式与预览模式共用相同的顶部导航、固定题说明、复制题目、检测结果说明、状态图例及操作栏；切换模式只改变下方模型卡片展示。

- 预览模式在供应商与模型名称下方显示组合检测状态：正常为绿、半降智为橙、降智为红，未检测与测试进行中为灰；复用详细模式判定规则，测试按钮保持在右侧。

- 预览模式卡片统一等高，画面与等待/失败占位区固定为 240px，糖果答案分隔线和卡片底部对齐；原始 HTML 按比例完整居中展示，不裁切、不拉伸、不改背景或原始内容。

- 鹈鹕预览画面支持双击放大查看；放大窗口使用原始 HTML 独立渲染，支持关闭按钮、Esc 和点击外围关闭，不改变检测数据。
- Intelligence workbench uses one full-column native scroll area for both gutters and centered content. Responsive padding preserves the original content width; no JavaScript wheel forwarding or blocking wheel listeners. Sidebar, nested content, dialogs, and popovers retain their own scrolling.

- 检测模型卡片支持长按顶部拖动排序：拖到另一张卡片后松开即可调整顺序，顺序保存在本机浏览器；测试、编辑、删除按钮保持点击功能，不会启动拖动，详细模式和预览模式共用同一排序。

- 智力检测添加模型和编辑模型弹窗统一使用自定义选择器：模型按供应商分组，思考强度和等待时限使用相同的圆角悬浮列表；选中高亮、点击外部关闭，移除原生下拉展开的巨大黑色选项面板，弹窗标题、间距、按钮和表单布局保持统一。
- 添加检测模型弹窗底部将刷新模型列表保留在左侧，取消与保存检测目标按钮统一靠右排列。
- 弹窗选择器会根据可用空间自动向上或向下展开；编辑弹窗标题栏在内部滚动时保持固定，避免打开思考强度或等待时限后标题和供应商信息被裁掉。


## 修改流程

1. 先阅读 `AGENTS.md`、`README.md` 和 `plugins/personal-toolbox/config/patches.json`。
2. 优先修改 `plugins/personal-toolbox/` 中对应的源文件。
3. 如果新增或改变功能，同步更新 `plugins/personal-toolbox/config/patches.json` 的 `features`，同步更新插件内 `docs/MAINTENANCE.md`；根 `AGENTS.md` 仅保留入口。
4. 修改后运行：

```powershell
node plugins/personal-toolbox/tools/apply.mjs --check
node plugins/personal-toolbox/tools/apply.mjs
```

5. 对修改过的 JavaScript 文件运行 `node --check 文件路径`。
6. 不要删除或清空 `plugins/personal-toolbox/`，不要把官方文件覆盖回补丁源文件。

## 更新依赖

更新时使用根目录的 `update-deepseek-harness.bat`。它会先备份 `plugins/personal-toolbox/`，再更新依赖、检查兼容性并恢复所有本地定制。

如果只运行了 `npm install`，启动 `start-deepseek-harness.bat` 时也会自动重新应用补丁。

启动器会把依赖版本与 `plugins/personal-toolbox/`（排除 archive）文件的 SHA-256 指纹写入临时标记；只在用户自行启动时加载新的后台代码。日常编辑/构建不调用启动器、不自动重启。

如果发现上游版本与 `plugins/personal-toolbox/config/patches.json` 不一致，不要强行覆盖；先报告版本不兼容，并保留现有 `plugins/personal-toolbox/`。

## 数据安全

不要修改、删除或清空用户数据目录。供应商设置、API 密钥、余额查询配置和会话数据独立保存，不能为了修复界面而重置。

## 给 AI 的简短提示词

可以把下面这句话发给任何 AI：

> 请先阅读项目根目录的 `AI-MAINTENANCE.md`、`AGENTS.md`、`README.md` 和 `plugins/personal-toolbox/config/patches.json`。修改 DeepSeek Harness 时只编辑 `plugins/personal-toolbox/` 源文件，不要只改 `node_modules`；修改后运行补丁检查、补丁应用和 JavaScript 语法检查，并保留现有配置、API 密钥和其他定制功能。

- 智力检测统一为鹈鹕 SVG + 糖果推理组合：新旧目标每轮并行请求两题，独立显示进度和失败原因，合并为一条 questions 历史；动画下方显示模型实际糖果答案（21 通过，29 或其他数值保留原值）；两题成功绿、一题成功橙、全失败红、未检测灰；默认糖果题使用指定数量表且不泄露答案，兼容旧默认提示词并保留自定义配置和历史；组合结果仍支持打开生成文件夹。

- 智力检测三种弹窗选择器使用顶层 Popover 浮层，避开弹窗滚动裁切；按屏幕空间上下展开并限制高度、独立滚动，统一边框阴影，支持键盘选择与 Esc 先关闭列表。
- Provider settings include an enable/disable switch. Disabling preserves models and credentials while blocking chat, catalog, and intelligence-test requests; re-enabling restores use.

- 鹈鹕放大预览沿用卡片已确定的页面尺寸，仅对外层等比例缩放；不扫描动画元素或循环修改 iframe 视口，窗口贴合画面，避免比例漂移和额外黑色留边，原始 HTML 保持不变。

- 智力检测每轮重新请求两题，鹈鹕返回后立即自动保存原始 HTML 到 output/intelligence-tests；按轮次保存独立文件并记录路径，重复导出同轮不重复创建；标注本轮进度、最近结果时间及保存状态，文件保存失败独立提示；浏览器记录写入失败仍显示本轮结果并提示，不静默退回旧画面。

- 智力检测完整历史改用 IndexedDB 异步顺序保存，自动迁移并保留旧 localStorage 记录副本；加载期间的新结果和清除操作按序合并，读取失败不覆盖原数据库；保存失败保留本轮画面并提供 JSON 备份导出，显示读取和保存状态。

- 同一供应商允许同一上游模型绑定多个命名 API 密钥；重复模型自动生成本地选择器别名，发送请求时仍使用原始上游模型 ID。

- 智力检测逐题校验本轮请求编号、供应商和模型，保留上游响应 ID 和耗时；本机请求编号不匹配仍拒绝，上游响应 ID 重复仅作提示，并区分正文相同与不同，不直接判失败或隐藏答案、预览；答题状态按本次实际返回内容计算，缓存疑点单独显示“生成新鲜度待确认”；原提示词不变，不声称客户端能强制绕过供应商缓存；旧失败记录保留，下一轮使用新规则。

- 智力检测为支持的 HTTP 适配器逐题记录真实 fetch 尝试次数、响应次数、状态、响应头等待与正文首段耗时、正文 SHA-256 及白名单响应头；全部目标可打开请求核查弹窗，不记录密钥、请求头、地址或正文副本；独立比较同供应商同模型的完整长正文，即使响应 ID 变化也提示疑似重复，短数值相同不据此判缓存，不把 HTTP 已外发当作供应商重新生成的证明；提示词、评分和普通聊天不变。

- 智力检测请求核查默认以白话结论显示每题请求情况、重复情况和下一步，耗时简写；请求编号、哈希与响应头收进默认关闭的技术详情，同一弹窗单层滚动；缺少记录不等于未发送，已响应不等于重新生成，不改变题目、请求、评分或历史数据。
